# Sri Krishna Cloud Kitchen Launch

Build a production-ready, fully responsive restaurant website for Sri Krishna Cloud Kitchen in गढ़ा, जबलपुर, मध्य प्रदेश based on the attached specification. Use the attached official logo and match the provided landing page design reference (Sri Krishna Home · Desktop.png) with client-side routing for Home, Menu, About, and Contact pages, centralized menu data, and the Zomato/Swiggy order redirect modal.
